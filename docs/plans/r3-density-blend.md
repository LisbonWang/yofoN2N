# r3 递归方案：r1/r2 处理结果的密度自适应混合（方案 A，已被取代）

> 状态：**已被方案 B（`recursive-blend-at-r1.md`）取代，降级为对照方案**。
> 本文档的机制分析（§1 学生比目标更干净一层）、已训完的 128 链（r0~r3）与
> 分带验证实测（§5.1）仍然有效，作为方案 B 的终点预期基线保留。不再扩展。

## 1. 关键机制：half→full 训练下「学生输出比监督目标更干净一层」

这是理解 r3 的**唯一关键**，必须先讲清：

训练 `even/odd → target` 时，`target` 里与半视图输入**独立**的残留噪声会被
模型平均掉（Noise2Noise 成分）。所以学生输出 ≈ 信号 + 更少噪声，**噪声水平
低于 target**——而不是等于 target。

128 窗口递归的实测已反复印证这一点：

| 轮次 | 监督目标（immerkaer σ） | 学生输出 = 下一轮目标（immerkaer σ） | 输出比目标 |
| ---- | ---------------------- | ------------------------------------ | ---------- |
| r0 → r1 | full = 0.0151 | full.dn_1 = 0.0085 | 再干净 ~43% |
| r1 → r2 | full.dn_1 = 0.0085 | full.dn_2 = 0.0055 | 再干净 ~35% |

即：**混合操作只决定「监督目标」的密度分布；最终决定去噪强度的是「学生
输出 = 目标再压一层」**。两者不是一回事，不能混为一谈。

## 2. r3 的最终效果（修正后的精确语义）

把「目标 → 学生输出再压一层」套到混合上，r3 训练完的学生 M₃ 输出是：

| 密度区 | 混合目标 | 学生 M₃ 输出（≈目标再压 ~35%） | 相对 r2 |
| ------ | -------- | ------------------------------ | ------- |
| 软组织（低密度） | r1（0.0085） | ≈ 0.0055 | **≈ r2（追平，不超越）** |
| 骨 / 牙釉质（高密度） | r2（0.0055） | < 0.0055 | **> r2（超越）** |

因此 r3 的实质是**密度分级的递归深度**：

- **软组织区封顶在 r2**：目标给 r1（噪声更高），N2N 压一层后恰好追平 r2，
  不再继续超越；
- **骨区在 r2 上再递归一层**：目标给 r2，N2N 再压一层，**超越 r2**。

> 注意：这不是"软保守（停在 r1）/ 骨激进（停在 r2）"的静态选择，而是
> "软组织少递归一层、骨区多递归一层"。软组织最终也到 r2 水平，只是相对
> 骨区**不继续往下压**——这正是"保护软组织细节"的正确落地方式（递归越深，
> 噪声越低，但也越可能过平滑）。

### 为什么还要混合（而不是全程用 r2 目标）

若不混合、全程用 r2 目标，软组织区也会被 N2N 压到 < r2（和骨区一样超越），
细节损失更多。混合给软组织一个"更弱的递归上限"（r1 → 只到 r2），骨区才
继续往下递归。所以混合的**意义不是"选 r1 还是 r2"，而是"给不同密度区设置
不同的递归深度"**。

## 3. 混合规则（目标层）

逐体素，键 = **r2 的 CT 值**（μ 域，已去噪），`lo=0.2`、`hi=0.4`：

```
w(v) = 0                             v <= lo          -> 纯 r1（软组织上限）
w(v) = smoothstep((v-lo)/(hi-lo))    lo < v < hi      -> 平滑 crossfade
w(v) = 1                             v >= hi          -> 纯 r2（骨区继续递归）

target = r1 + w(r2) · (r2 - r1)
```

- `smoothstep(t) = t²(3-2t)`：C¹ 连续，两端斜率为 0，过渡带无梯度断点。
- **分水岭 0.3 = (lo+hi)/2**，此处 `w = 0.5`。
- 过渡带 `(0.2, 0.4)` 正是"软组织 → 骨"的 μ 值过渡区间，物理上连续。

### 为什么键用 r2 的 CT 值（而非 full 或 r1）

`full` 含噪，用它做键会把噪声抖动带进混合 mask，在过渡带产生高频伪边界。
r2 已去噪（immerkaer 0.0055），体素值平滑，做键不引入噪声抖动；且 r2 的
强度最接近"去噪后的真实组织密度"。`--mask-source high`（默认）即取 r2。

## 4. 密度分区（μ 域，参考值）

| 分区 | r2 值域 | 物理含义 | 目标来源 |
| ---- | ------- | -------- | -------- |
| low | `0.01 < v ≤ 0.2` | 水 / 软组织（空气 `v≈0` 已排除） | r1 |
| mid | `0.2 < v < 0.4` | 软组织 → 骨 过渡 | smoothstep crossfade |
| high | `v ≥ 0.4` | 骨 / 牙釉质 / 高衰减 | r2 |

（`0.01` 为组织阈值，与噪声估计器的 `tissue_floor` 一致，用于剔除空气恒定区。）

## 5. 两层验证（目标层 + 输出层，缺一不可）

**目标层门控**（生成 `full.dn_3d_128_r3` 时，`blend_dn_targets.py` 输出）：
只验证混合目标分布正确——low 带 `target ≈ r1`、high 带 `target ≈ r2`、每带
`target ≤ max(r1,r2)`（凸组合必然成立）。**这只是"监督目标生成正确"的 sanity
check，不是效果判据。**

**输出层门控**（训练完 M₃ 后，真正的效果判据）：用 M₃ 对 `full`（train/val）
或 `test`（保持隔离）tiled 推理，分带测 immerkaer σ：

- 软组织带输出 **≈ r2**（0.0055 上下，不显著高于 r2，即"封顶"生效）；
- 骨带输出 **< r2**（超越 r2，即"继续递归"生效）；
- 全带都 **< full**（0.0151，去噪方向正确）。

> 之前把"目标分布"当成"最终效果"是错的。输出层门控才是 r3 效果的真判据，
> 需在 M₃ 收敛后补做。

### 5.1 输出层门控实测结果（2026-09-17，test 集 10 例，已通过）

M₃（r3 best.pt，ep83）与 M₁/M₂ 同用 `infer_volume_3d_tiled`（240×240×112 步长、
H/W+D 重叠 16、trapezoid 融合）对每个 test 例的 `full` 推理；分带键 = **M₂ 输出**
（μ 域，> 0.01），`lo=0.2`/`hi=0.4`。工具 `scripts/eval_rounds_banded.py`，
报告 `docs/reports/r3-banded-validation.md`，数据 `outputs/eval_1609v2_h2f_128_banded_test.json`。

分带 Immerkaer σ（10 例均值）：

| 密度带 | M₁ | M₂ | **M₃** | full | M₃/M₂ | M₃ vs full |
| ------ | -- | -- | ------ | ---- | ----- | ---------- |
| low（水/软组织） | 0.00525 | 0.00403 | **0.00397** | 0.01358 | **0.987×** | −70.7% |
| mid（过渡） | 0.00440 | 0.00306 | **0.00296** | 0.01338 | 0.967× | −77.9% |
| high（骨/牙釉质） | 0.00564 | 0.00432 | **0.00388** | 0.01422 | **0.898×** | −72.8% |
| **全局** | 0.00518 | 0.00397 | **0.00388** | 0.01363 | 0.979× | −71.5% |

判据全部成立，且逐例一致（10/10）：

- **软组织封顶 ✅**：low 带 M₃/M₂ = 0.987×（仅再压 1.3%，与 r2 持平，未越过）；
- **骨区超越 ✅**：high 带 M₃/M₂ = **0.898×**（在 r2 上再递归一层，噪声再降 ~10%）；
- **全带低于 full ✅**：三个带都远低于 full（−71~78%）。
- 单调性检验（关键）：`M₃/M₂` 随密度**单调下降**，low 0.987 > mid 0.967 > high 0.898
  —— 正是"软组织少递归一层、骨区多递归一层"的直接证据，说明混合的密度分级生效，
  而不是全局一个强度。

> 注意：**目标层混合比 ≠ 输出层效果**。r1→r2 单步实测只再压 ~35%（目标层），而 r3 的
> 相对 r2 增益只有 1.3%/10%（输出层），说明递归已接近该窗口下的收敛平台——软组织几乎
> 不再下降正是设计意图（避免过平滑），骨区仍有余量。

## 6. 单轮流水线（三步）

```bash
# ① 生成混合目标（纯 numpy，无模型，服务器上跑，约几分钟）
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 /opt/anaconda3/envs/pytorch201/bin/python \
  scripts/blend_dn_targets.py \
  --manifest /data/raid0/yyc/AIReduceNoise2/splits_1609v2.json \
  --r1-suffix dn_3d_128_r1 --r2-suffix dn_3d_128_r2 \
  --target-suffix dn_3d_128_r3 --lo 0.2 --hi 0.4 --kind smoothstep \
  --splits train,val

# ② 派生 config（已写好：configs/1609v2_unet3d_h2f_128_dn_3d_128_r3.yaml）
#    mappings -> full.dn_3d_128_r3，run_dir -> ..._dn_3d_128_r3

# ③ 训练（热启动 r2 best.pt，optimizer/scheduler 冷启动）
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 /opt/anaconda3/envs/pytorch201/bin/python \
  scripts/train_voxel.py --arch unet3d \
  --config configs/1609v2_unet3d_h2f_128_dn_3d_128_r3.yaml \
  --manifest /data/raid0/yyc/AIReduceNoise2/splits_1609v2.json \
  --run-dir runs/1609v2_n2n_3d_h2f_128_dn_3d_128_r3 \
  --init-weights runs/1609v2_n2n_3d_h2f_128_dn_3d_128_r2/best.pt
```

- **热启动选 r2 best.pt**：r3 目标在形态上更接近 r2（high 带完全等于 r2），且
  r2 是最新收敛解；沿用铁律 `--init-weights`（禁 `--resume`）。
- **test 永不进教师/混合**：`--splits train,val`，test 保持隔离。
- **控制变量只换目标**：窗口/stride/patch/arch/lr/seed 与 r1、r2 全同。

## 7. 关键规则（沿用递归铁律 + 新增）

1. 混合输入是 r1、r2 的**已生成目标**（`full.dn_3d_128_r1.raw` /
   `full.dn_3d_128_r2.raw`），无需重新降噪；两者是同一 `full` 的两次降噪，
   体素一一对应、同 shape，纯逐体素线性插值，无需配准。
2. 断点续跑安全：已存在的 `full.dn_3d_128_r3.raw` 跳过；manifest 注册幂等。
3. `--kind` 可选 `smoothstep`（默认，推荐）/ `cosine` / `linear`；`--lo`/`--hi`
   可调，但须 `hi > lo`。

## 8. 风险与备选

- **"输出再压一层"的幅度是经验值**：~35% 是 r1→r2 的实测，不代表 r3 精确
  复现；软组织是否恰好"≈r2"需输出层门控实测确认，若偏糊/偏噪只调 `--lo`/`--hi`
  重跑混合（秒级）即可，无需重训。
- **汇报口径**：不再说"低密度保留 r1 / 高密度达到 r2"，改为"**软组织封顶 r2、
  骨区超越 r2**"；并强调全局噪声削减仍会整体 > r2（骨区拉动），但不单调。
- **备选键**：若想按 r1 强度分带，`--mask-source low`；若想用更干净的二阶键，
  可先对 r2 再做一次平滑（当前 r2 已足够平滑，暂不需要）。
- **上限是否可调**：若希望软组织也"超越 r2"（不要封顶），把 low 带目标从 r1
  换成 r2 即可（即退化回全程 r2 目标）；当前设计默认软组织封顶，需临床确认。
