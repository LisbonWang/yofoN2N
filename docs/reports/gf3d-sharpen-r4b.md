# 3D 引导滤波锐化（r4b）——实现与验收

**结论**：已实现 3D 引导滤波锐化算法（`src/cbct_n2n/filters/guided.py`）并应用于
`full.bhc.r4b.raw`。参数固定为 **`wiener` / radius=2 / k=8 / σ_flat=0.001107**，
只留 **`strength`** 一个幅度旋钮：

- 骨小梁 ROI 的 σ **0.003019 → 0.005846（+93.6%）**，
- 平坦软组织 ROI 的 σ **0.001107 → 0.001166（+5.3%，绝对值 +5.9e-5）**，
- 骨/平选择性 **2.727 → 5.015**（噪声参考体只有 1.136，即噪声把两者抹平），
- 全组织**分带比例不变**：`high/low` 0.5473 → **0.5477**。

**strength 已由人工判定"偏强"，并且要求"不产生黑边"**（见 §3.1 / §3.2）。
按此要求渲染的候选档（均 k=8、σ_flat、同 eps；"暗化"= `darken_visible_max`）：

- `--radius 1`，s=1.0（骨 +80.1% / 暗化 0.2571，**−51%**）
- `--radius 1 --max-darken 0.15`，s=1.0（骨 +72.1% / 暗化 **0.1230**，−77%）
- `--radius 2 --max-darken 0.15`，s=1.0（骨 +90.8% / 暗化 0.1455，−72%；但 `high/low` 升 9%，**不推荐**）
- **`--radius 1 --strength 1.15`**（骨 **+92.4%** ≈ 原档 +93.6% / 暗化 0.2956，**−44%**）
- **`--radius 1 --strength 1.15 --max-darken 0.15`**（骨 +82.5% / 暗化 **0.1291**，**−76%**，**推荐**）

**关键修正（§3.3）**：`radius` 同时改"多强"，所以同 strength 比 `r=1` vs `r=2` 是在比两种
不同的东西。把 strength 抬到 **1.15** 让骨增益追平后，`r=1` 只花 **44% 的黑边**、组织下冲
腰斩、平坦代价只多 1.0pp。**"既要锐又不许黑边"的正确解法是先降 radius 再抬 strength，
`--max-darken` 只作最后一道保险，且必须挂在窄窗上**（挂宽窗几乎无效还会造台阶）。

## 2. 算法

He, Sun & Tang (2010) 由 2D 图像推广到 3D 体数据。窗口内把体数据建模为导引
`I` 的**线性**函数，再把逐窗系数在重叠窗口上平均：

```
a = cov(I,p)/(var(I)+eps)      b = mean(p) − a·mean(I)
A = box_r(a)                   B = box_r(b)
q = A·I + B
```

自导引（`p == I`）时 `a = var/(var+eps)` **恰好是局部 Wiener 增益**——
即"一个起伏里有多少比例是信号"的最优比例，`a→0` 于平坦区、`a→1` 于边缘。
所有窗口统计量都是可分离 box 均值（6 次 `uniform_filter`），因此**每体素 O(1)，与 r 无关**。

### 两种锐化模式

设 `m = box_r(p)` 为局部均值：

| 模式 | 公式 | 平坦区行为 |
| ---- | ---- | ---------- |
| `detail`（教科书） | `out = q + s·(p − q)` | 提升整个残差 `(1−a)(p−m)`，平坦区 `a→0` ⇒ 残差**就是噪声**，被放大 s 倍 |
| `wiener`（**本项目默认**） | `out = p + s·(q − m)` | 只提升**结构估计**；因 `q−m = A·(p−m)`，先乘 `A` 再放大 ⇒ 平坦区 `A→0` 不动 |

**关键**：平坦区噪声增益有解析式 `1 + s/(1+k²)`（`eps=(kσ)²`）。
k=2 → 1.20、k=4 → 1.059、k=8 → 1.015。k 定"选择性"，s 定"幅度"。
该解析式在合成纯噪声上已被测试断言（容差 0.02）；
而 `detail` 模式在同样参数下增益 > 1.70，两者相差数量级
（见 `test_classic_detail_mode_pays_the_full_noise_price`）。

### 内存

360×640×640 float32 = 590 MB，滤波需约 10 份 scratch（≈6 GB）。
`guided_filter_3d` 沿 z 分 slab 流式处理，每块读取时带 **`2r` 的 halo**
（不是 `r`——两级串联 box 均值需要这么多支撑），端点用 `mode="nearest"` 使被裁掉的
halo 精确。因此**分块结果与整体结果逐位相同**：slab ∈ {1,3,4,5,7,16} 的最大差
**全部为 0.0**（测试参数化覆盖）。

## 3. 参数选择依据

扫描 24 个等距层面（与 Immerkaer 估计器同一批层面），radius ∈ {2,4} ×
k ∈ {1,2,4,8} × strength ∈ {0.5,…,3}。完整表见 `gfsharp_sweep.md`，摘要：

| 配置 | 骨增益 | 平坦代价 | 增益/代价 | 骨/平 |
| ---- | ------ | -------- | --------- | ----- |
| plain（锐化前） | – | – | – | 2.727 |
| noisy（噪声参考） | +438% | +1192% | 0.37 | 1.136 |
| r2 k8 s0.5 | +46.7% | +2.6% | 17.7 | 3.898 |
| **r2 k8 s1.0** | **+93.6%** | **+5.3%** | **17.7** | **5.015** |
| r2 k8 s2.0 | +180.5% | +10.6% | 17.0 | 6.914 |
| r2 k1 s1.0 | +96.9% | +77.7% | 1.25 | 3.022 |

三条规律：**k 只影响选择性**（增益/代价 3.2 → 10 → 32 → 90+ 随 k 单调），
**strength 只缩放幅度**，**radius 几乎无影响**（r=2 与 r=4 在 k=8 下骨/平
5.015 vs 4.972，而 r=2 的窗口更小、halo 更薄）。故取 **r=2**。

σ 的选取是个**曾经算错**的量：初始用全组织掩膜实测 σ=0.003487，但该值
**把骨结构也算进噪声**；平坦 ROI 实测 σ=**0.001107**，前者高估 3.2×。
现以 `--sigma-source flat`（默认）取值，k 才如实读作"多少个残余噪声底"。

### 3.1 strength 是纯线性幅度旋钮 —— "看着过了"该调哪个

人工判定 s=1.0 偏强后的定量回答。同一 `eps`（`7.844e-05`）下把 strength 扫细，
指标由 `scripts/guided_sharpen_compare.py` 在**同一批体素**上重算
（`gfsharp_compare.md`）：

| strength | 骨 ROI σ | 骨涨幅 | 平坦 ROI σ | 平坦代价 | 增益/代价 | 平坦区解析增益 1+s/(1+k²) |
| -------- | -------- | ------ | ---------- | -------- | --------- | ------------------------ |
| 0.3 | 0.00386 | +28.0% | 0.00112 | +1.6% | 17.63 | ×1.0046 |
| 0.4 | 0.00415 | +37.3% | 0.00113 | +2.1% | 17.64 | ×1.0062 |
| 0.5 | 0.00443 | +46.7% | 0.00114 | +2.6% | 17.65 | ×1.0077 |
| **0.6** | 0.00471 | **+56.1%** | 0.00114 | **+3.2%** | 17.66 | ×1.0092 |
| **0.8** | 0.00528 | **+74.9%** | 0.00115 | **+4.2%** | 17.67 | ×1.0123 |
| 1.0 | 0.00585 | +93.6% | 0.00117 | +5.3% | 17.65 | ×1.0154 |
| （参考）noisy | 0.01625 | +438% | 0.01431 | +1192% | 0.37 | – |

**strength 严格线性**：骨涨幅 ÷ strength 在每一行都是 93.4 ± 0.2%，
增益/代价比在 0.3→1.0 全程钉在 **17.6**。所以：

- **调 `--strength` 只改"多少"，不改"性质"**——往下调不会因此变脏，
  也不会改善信噪权衡，就是等比缩。s=0.6 即"骨增益打到 60%"。
- **要改善权衡本身（骨增益不变、平坦代价减半）动的是 `--eps-k`**，不是 strength：
  k=8 → 12 时骨增益 +93.6% → +92.6%（几乎不变）而平坦代价 +5.3% → **+2.4%**，
  增益/代价 17.65 → **38.59**（k=12 行见 `gfsharp_sweep_low.md`）。
  机理是 `a = var/(var+eps)`：eps 变大后**弱起伏被压、强边缘仍保留**全增益，
  即"只锐化确凿的结构"。故若不满的是**组织里的颗粒感**而非结构本身，该调 k。
- **`--radius` 不是旋钮**：k=8 下 r=2 与 r=4 的选择性 5.015 vs 4.972（§3）。

**自检**：`guided_sharpen_compare.py --verify` 把裁剪重建与磁盘上的三个已写体逐一比对，
`s=0.6 / 0.8 / 1.0` 均为 **max|crop diff| = 0.000e+00（bit-for-bit）**，
证明图上的每一档就是它标称的那一档。该性质另有
`tests/filters/test_guided_sharpen_compare.py` 参数化覆盖 s ∈ {0, 0.5, 1.0, 2.0}。

**回调的第二个好处：振铃/越界同样线性下降**（§4.3 的口径，组织掩码取自输入体）：

| strength | 组织 σ<0 占比 | 组织最小值 | 组织 p99.99 | 空气最深值 |
| -------- | ------------- | ---------- | ----------- | ---------- |
| 0.6 | 0.25670% | −0.2242 | 1.2512 | −0.3758 |
| 0.8 | 0.37438% | −0.3048 | 1.2678 | −0.4760 |
| 1.0 | 0.47229% | −0.3937 | 1.2823 | −0.5761 |
| 2.0 | 0.82223% | −0.8379 | 1.3577 | −1.0767 |

`s=1.0 → 0.6` 把组织下冲占比砍掉 **46%**、最深下冲从 −0.394 收到 −0.224。

### 3.2 黑边（暗化振铃）的机理与三条杠杆

**机理**：`field ≈ A·(p − m)`，在强边缘 `A → 1`，算子退化成**窗半径为 r 的 unsharp mask**
（`out ≈ p + s(p − m)`）。于是**当某处低密度结构比窗口更窄时，它的局部均值 `m` 被两侧
密质骨拉高，沟底就被压到真值以下**——这就是那条黑线。

本卷最深处在一条约 4 体素宽的低密度沟（自动定位到 `z=214 y=409 x=214`，与独立探针一致）：

```
offset   −4      −3      −2      −1       0      +1      +2      +3      +4
plain  0.496   0.345   0.348   0.467   0.938   1.270   1.492   1.539   1.143
r2 s=1 0.018  −0.182  −0.179  −0.033   0.732   1.269   1.659   1.749   1.762
```

沟底真值约 0.35（软组织），被压到 **−0.182**；两侧壁同时被抬高 +0.28。

**`--eps-k` 碰不到它（重要负结果）**：k=4 / 8 / 12 在最深处的暗化是
**−0.528 / −0.527 / −0.527**，按距离分带的暗化占比逐项一致（1.056% / 1.056% / 1.055%）。
因为强边缘处 `var ≫ eps`，`a` 与 eps 无关。**只有 radius、strength 与显式上限能动它。**

| 配置（均 k=8） | 最深**可见**暗化 | 可见暗化 p99.9 | 组织 σ<0 占比 | 组织最小值 | 骨 σ 增益 | 平坦代价 | high/low |
| -------------- | ---------------- | -------------- | ------------- | ---------- | --------- | -------- | -------- |
| plain（r4b） | 0 | 0 | 0.0000% | +0.0100 | – | – | 0.5473 |
| r=2, s=1.0（§3 原推荐） | 0.5275 | 0.0769 | 0.4723% | −0.3937 | +93.6% | +5.3% | 0.5477 |
| r=1, s=1.0 | 0.2571 (−51%) | 0.0383 | 0.1978% | −0.2141 | +80.1% | +5.5% | **0.5038** |
| r=1, s=1.0, `--max-darken 0.15` | **0.1230 (−77%)** | 0.0338 | 0.1753% | −0.1012 | +72.1% | +5.5% | 0.5370 |
| **r=1, s=1.15** | 0.2956 (−44%) | 0.0441 | 0.2316% | −0.2487 | **+92.4%** | +6.3% | 0.5013 |
| **r=1, s=1.15, `--max-darken 0.15`** | **0.1291 (−76%)** | **0.0382** | 0.2064% | −0.1078 | +82.5% | +6.3% | 0.5420 |
| r=2, s=1.0, `--max-darken 0.15` | 0.1455 (−72%) | 0.0602 | **0.4161%** | −0.1231 | +90.8% | +5.3% | **0.5979 ↑** |

**三个"最大暗化"不是同一个数**（表中用加粗的那一个，因为只有它是黑边）：

| 量 | 范围 | r=1 s=1.15 实测 |
| -- | ---- | --------------- |
| guard 打印的 `max darkening` | **全卷**（含空气） | 0.3291 |
| `overshoot.darken_max` | 仅组织 | 0.3100 |
| `overshoot.darken_visible_max` | 组织 ∧ 输入 > `VISIBLE_FLOOR` | **0.2956** |

三者恒满足"全卷 ≥ 组织 ≥ 可见组织"；空气与"本来就黑"的体素会把前两个抬高。
**所以不要拿图上的窗内最大值去校对表里的全局值，也不要用 guard 的打印值当黑边深度**。

读法：

1. **降 `radius` 是最划算的一条**——halo 宽度就是高通的窗半径。`r=2 → 1` 把最深暗化
   砍掉一半。3³ 的窗比 4 体素宽的沟更窄，均值不会被两侧壁污染。
   → **"窗比你想保护的暗结构更宽"就是出黑线的条件**；`r=1` 保护 ≥3 体素宽的结构。
   **但 `r=2→1` 同时把算子整体变弱了**（同 strength 下骨增益 +93.6% → +80.1%），
   所以同 strength 的对比不公平——修正见 **§3.3**。
2. **`--max-darken Δ` 直接给暗化量封顶**（本次新增能力，默认关）：
   `dark' = Δ·(1 − e^(−dark/Δ))`，小暗化原样通过（`f'(0)=1`，不引入台阶），大暗化饱和到 Δ。
   **只封暗的方向**，因为骨小梁的对比度有一半来自压暗骨髓腔——两侧都封等于把锐化关掉
   （实测双侧 Δ=0.10 → 骨增益 **+0.0%**）。
3. **它只削尾巴，不动主体**：`r=1` 加不加上限，可见暗化的 **p99.9 只从 0.0383 到 0.0338**，
   但最深值从 0.2571 降到 0.1230。也就是"99.9% 的体素完全感觉不到差别，只是那条最黑线没了"。
4. **宽窗上重钳位有副作用**：`r=2 + 0.15` 的 `high/low` 升到 0.5979（比 plain 高 9%）。
   大力钳位在宽窗上会把沟底压成平台，平台自己又造出高频台阶。`r=1` 下没有这个现象
   （0.5370，仍低于 plain）。**所以"降 radius"和"封顶"不是替代关系，先降 radius 再封顶才干净。**

**新 QC 指标（一处重要修正）**：原先的 `tissue_below_0_pct` **看不见黑边**——一个本来就贴在
组织下限 0.01 的体素只要再暗 0.01 就被计入，于是该指标被"本来就是黑的"体素占满。实测
加暗化上限时它只从 0.82% 动到 0.69%，而可见暗化始终是 0.53。新增
**`darken_visible_max` / `darken_visible_p999`**（只统计输入 `> VISIBLE_FLOOR = 0.15` 的体素，
即任何显示窗里都明确是组织的位置）才看得见要修的东西。该语义由
`test_visible_darkening_ignores_voxels_that_were_already_black` 钉住。

**结论**（**`radius` 必须先把骨增益对齐再比**，理由见 §3.3）：

- 想**彻底不再出现黑边，同时保住接近原档的骨增益**：**`--radius 1 --strength 1.15 --max-darken 0.15`**
  （骨 +82.5%，最深可见暗化 **0.1291**，可见 p99.9 0.0382，`high/low` 0.5420 ≈ plain）——**推荐**
- 想**骨增益与原档持平、只削黑边**：`--radius 1 --strength 1.15`
  （骨 **+92.4%** ≈ 原档 +93.6%，最深可见暗化 0.2956，**−44%**，组织下冲占比 −51%）
- 想**少动参数、只降一档**：`--radius 1`（s 保持 1.0，骨 +80.1%，暗化 −51%）
- **不推荐** `--radius 2 --max-darken 0.15`：它几乎没救回组织下冲（0.4723% → 0.4161%），
  `high/low` 还上抬 9%（造台阶），被上面两个 r=1 档全面支配。**封顶必须挂窄窗，不能挂宽窗。**

### 3.3 `radius` 同时改"多强" —— 必须先对齐骨增益再比黑边（含 `high/low` 的误读修正）

§3.2 里"`r=2→1` 骨增益只少 14%"是**同 strength 的对比，不公平**：`radius` 既改 halo 宽度、
也改算子的整体增益。实测每单位 strength 的骨 ROI σ 涨幅：

```
r=2 : 93.4 %/unit      （§3.1 的 0.3→1.0 全程常数）
r=1 : 81.4 %/unit      （0.8→1.5 共 5 点线性，见 gfsharp_compare_r1hi.json）
```

**所以要比黑边，先把 strength 抬到骨增益追平。** `r=1` 需要 s ≈ **1.15**：

| r=1 配置 | 骨 σ | 骨涨幅 | 平坦代价 | 骨/平 | 骨增益/代价 | 窗内最深处暗化 |
| -------- | ---- | ------ | -------- | ----- | ----------- | -------------- |
| s=0.8 | 0.00495 | +63.9% | +4.4% | 4.282 | 14.5 | 0.1758 |
| s=1.0 | 0.00544 | +80.1% | +5.5% | 4.657 | 14.6 | 0.2197 |
| **s=1.15** | **0.00581** | **+92.3%** | +6.3% | 4.932 | **14.7** | **0.2527** |
| s=1.3 | 0.00618 | +104.5% | +7.2% | 5.204 | 14.5 | 0.2856 |
| s=1.5 | 0.00667 | +120.9% | +8.3% | 5.560 | 14.6 | 0.3296 |

（"窗内最深处暗化" = 固定在 r=2 最差位置的那个 80×80 窗内的最大值，四档同一处。）

**对齐后的对照**：`r=1 s=1.15` 对比 `r=2 s=1.0` ——

| | 骨增益 | 最深可见暗化 | 可见 p99.9 | 组织 σ<0 占比 | 组织最小值 | 平坦代价 | 骨/平 |
| - | ------ | ------------ | ---------- | ------------- | ---------- | -------- | ----- |
| r=2, s=1.0 | +93.6% | 0.5275 | 0.0769 | 0.4723% | −0.3937 | +5.3% | 5.015 |
| **r=1, s=1.15** | **+92.4%** | **0.2956 (−44%)** | **0.0441 (−43%)** | **0.2316% (−51%)** | **−0.2487** | +6.3% | 4.932 |

**骨增益打平，黑边与组织下冲全部腰斩，平坦代价只多 1.0pp。** 这就是"既要锐又不许黑边"
的首选路径，也是 §3.2 里"降 radius 最划算"的定量版。

#### `high/low` 下降到 0.5038 不是噪声征兆（修正 §3.2 与 §4.1 的读法）

`r=1` 的 `high/low`（0.5038）**低于 plain**（0.5473），看起来像"骨/软对比度被削弱"。
拆开三个口径后，两种可能的解释只有一种成立：

| 观测量 | r=2, s=1.0 | r=1, s=1.0 | 差 |
| ------ | ---------- | ---------- | -- |
| 分带 `low` 涨幅（软组织带） | +96.7% | +95.2% | −1.5pp |
| 分带 `high` 涨幅（骨带） | +96.9% | +79.7% | **−17.2pp** |
| 平坦 ROI `fine` 八度涨幅（体素尺度 = 噪声处） | **+6.6%** | **+1.5%** | −5.1pp |
| 骨 ROI `fine` 八度涨幅 | +66.7% | +32.5% | −34.2pp |
| 骨/平 `fine` 选择性 | 10.1 | **21.7** | **×2.1** |

1. **假说 A"`r=1` 往软组织里多灌了噪声"被否定**：`low` 带涨幅几乎相同（+95.2% vs +96.7%），
   而平坦 ROI 的**八度 `fine`（噪声所在）涨幅 `r=1` 只有 +1.5%，`r=2` 是 +6.6%**。
   `r=1` 往噪声带里放的能量是 `r=2` 的 **1/4**。
2. **`high/low` 的缺口 100% 来自 `high` 带涨得少**——即骨带被增强得少，不是软带被增强得多。
   `high/low` 是**全卷的、由边缘主导的**统计量，混入了多孔骨/软组织边界体素，
   在此处并不度量"噪声有没有进来"。
3. **该用的判据是 patch 局部的八度对**：骨 `fine` vs 平 `fine` 的选择性，`r=1` 是 `r=2` 的
   **2.1 倍**。按这个口径 `r=1` 更好。

**结论**：`r=1` 是一个**整体更弱、但更选择性**的算子（骨 ROI 的每个八度都比 `r=2` 涨得少，
≈ 40–50%），而不是一个"更脏"的算子。所以：
- **`high/low` 下降不能直接判死**（升也不能直接放过——钳位造台阶会让它升到 0.5979）；
- 它只适合在 `radius` 固定时看"封顶有没有造台阶"，**不能用来跨 `radius` 选型**。

## 4. 验收结果（strength 1.0）

### 4.1 主表

`low`=软组织带 (0.01,0.2]、`mid`=过渡带 (0.2,0.4)、`high`=骨带 [0.4,∞)

| 方法 | low | mid | high | 全局 σ | high/low | 平坦 ROI σ | 骨 ROI σ | 骨/平 |
| ---- | --- | --- | ---- | ------ | -------- | ---------- | -------- | ----- |
| noisy（输入噪声参考） | 0.01759 | 0.01687 | 0.01673 | 0.01710 | 0.9511 | 0.014309 | 0.016253 | **1.136** |
| r3b | 0.00568 | 0.00343 | 0.00313 | 0.00426 | 0.5509 | 0.002014 | 0.003573 | 1.774 |
| plain（r4b） | 0.00478 | 0.00268 | 0.00262 | 0.00349 | 0.5473 | 0.001107 | 0.003019 | 2.727 |
| **sharp（s=1.0）** | 0.00940 | 0.00509 | 0.00515 | 0.00674 | **0.5477** | 0.001166 | **0.005846** | **5.015** |
| sharp（s=2.0） | 0.01404 | 0.00754 | 0.00769 | 0.01004 | 0.5478 | 0.001225 | 0.008469 | 6.914 |

**最重要的安全信号是 `high/low` 不变**（0.5473 → 0.5477）。若锐化在往体素尺度
重新灌噪声，`high`（高频主导）必然相对 `low` 抬升；它纹丝不动，说明提升的是
与频率无关的对比度，而不是噪声。

> 该读法**只在 `radius` 固定时成立**。跨 `radius` 时 `high/low` 会因算子变弱而下降
> （r=1 → 0.5038，低于 plain），而那不是噪声征兆——见 **§3.3** 的拆解。跨 `radius`
> 判"有没有进噪声"要用 patch 局部的八度对（骨 `fine` vs 平 `fine`）。

骨 ROI 与平坦 ROI 的绝对量级差 49 倍（+2.83e-3 vs +5.9e-5）。

### 4.2 分频验证（八度带）

`fine`≈体素尺度（噪声所在）、`mid`≈骨小梁尺度、`coarse`≈背景

| ROI | fine | mid | coarse | dc |
| --- | ---- | --- | ------ | -- |
| 平坦 plain→sharp | 0.001827 → 0.001947 (**+6.6%**) | 0.000624 → 0.000599 (−4.1%) | 0.000879 → 0.000845 (−3.8%) | 0.002929 → 0.002911 |
| 骨 plain→sharp | 0.035178 → 0.058630 (**+66.7%**) | 0.059227 → 0.073396 (+23.9%) | 0.093592 → 0.100174 (+7.0%) | 0.098701 → 0.098471 |

平坦 ROI 的涨幅**全部集中在最细的八度**，`mid`/`coarse` 反而略降；
骨 ROI 则**三个八度同时上升**。这与"平坦区只是噪声底被轻微缩放、骨区是结构被恢复"
一致。注意平坦区 +6.6% 高于纯噪声解析预测 +1.5%，差额来自该 ROI 内低幅度的
真实结构——它也在被合理地变陡，不全是噪声代价。

### 4.3 越界 / 振铃 QC

σ 看不见的一种失效：整体几乎不动、却在强边缘把少数体素的拉出值域。
故单列。**组织掩码取自输入体**（见 §5.2，这一点至关重要）。

| 方法 | 组织 σ<0 占比 | 组织最小值 | 全图 σ<0 占比 | 全图 σ>1 占比 |
| ---- | ------------- | ---------- | ------------- | ------------- |
| noisy | 2.84592% | −0.1122 | 7.901% | 0.00785% |
| r3b | 0.00001% | −0.0067 | 12.699% | 0.00779% |
| plain（r4b） | **0.00000%** | **+0.0100** | 13.059% | 0.00776% |
| **sharp（s=1.0）** | **0.47229%** | **−0.3937** | 13.473% | 0.01287% |
| sharp（s=2.0） | 0.82223% | −0.8379 | 13.680% | 0.02547% |

读法：

- **r4b 组织内一个负值都没有**（最小值恰好 +0.0100，即重建的组织硬下限）。
  与本项目既有结论一致——r4b 已退化成"全局最大平滑"、不在交付档位内。
  平滑到连边缘下冲都被抹平，正是它需要被锐化的原因。
- 锐化把 0.472% 的组织体素（约 46.3 万个，组织共 9804 万）带回 0 以下，
  最差 −0.394。**这仍只有原始噪声体的 1/6**（2.846%）。
  即：用 1/6 的越界代价换回 +93.6% 的骨纹理。
- **组织内不可能低于 `tissue_floor`**——那是重建的硬下限，所以所有负值都是
  锐化自身在强边缘（金属牙/皮质骨）产生的**振铃下冲**，`s=2.0` 时增至 0.822%
  且最深 −0.838。
- `σ>1` 占比只从 0.00776% 涨到 0.01287%，且组织 p99.99 仅由 1.1879 → 1.2823：
  **越界的是同几颗亮体素被推得更高，不是新体素越界**。

**若下游不能接受负值**：锐化后按 `np.maximum(out, 0.0)` 截断即可（不要截到
`tissue_floor`，那会把空气抬到 0.01）。本交付物**保持未截断**，把选择权留给使用者。

## 7. 已知限制

1. **Immerkaer σ 不能区分噪声与纹理**——它是高频能量，二者都算。所以本文的
   论据一律建立在"可证明平坦的 ROI"与"可证明有骨小梁的 ROI"的**对比**上，
   而非任何单一 σ。
2. **骨带 σ 被金属牙/皮质骨的强边缘主导**，不可单独采信，必须落到 ROI 大图看骨小梁。
3. **`hf_correlation_vs_noisy` 不是证据，只是诊断**。曾想用它区分结构/噪声，
   实测在平坦组织里对每个滤波、每个尺度都饱和在 ~0.99。原因：递归链每一轮
   都是近线性的高频衰减器（平坦区与输入高通的相关性 r0→r4b 恒在 0.991–0.999）。
   数值高只说明"它是输入的缩放副本"，**不说明它是信号**。sidecar 的 `note` 已写明。
4. **平坦 ROI 的 +5.3% 不是纯噪声代价**（§4.2），但也没有独立测量能把它精确
   拆成"噪声"与"低幅结构"两部分。
5. `mode="detail"` 保留但**不推荐**用于本场景（噪声增益 1.70+）。
6. **"黑边"没有可直接判定的金标准**。本报告用"最深可见暗化"（输入 > 0.15 的体素里
   被压下去的最大量）作为代理，它抓住了最坏的那条线，但**说不出几条线算多、多深算可见**
   ——最终仍是人眼判断。`--max-darken` 的绝对标定同理（见 §8）。
   注意同时存在三个"最大暗化"口径（全卷 / 组织 / 可见组织，见 §3.2），**只有可见组织那个是黑边**。
7. **`tissue_below_0_pct` 不能用来判断黑边**（§3.2）。它把贴在组织下限、暗 0.01 就过阈值的
   体素算了进来，加暗化上限时它只从 0.82% 动到 0.69%。同理 `all_below_0_pct` 主要是空气。
8. **`band_differentiation_high_over_low` 不能跨 `radius` 比较**（§3.3）。它是全卷、
   边缘主导的统计量：`r=1` 的下降（0.5038）来自骨带被增强得少，不是软组织进了噪声
   （`low` 带涨幅 +95.2% vs +96.7%，几乎相同；平坦 ROI 的 `fine` 八度 `r=1` 只涨 +1.5%
   而 `r=2` 涨 +6.6%）。该指标只在 `radius` 固定时用于"看钳位有没有造台阶"。
9. **"窗内最大暗化"（图上的标注）与"全卷最深暗化"（表里的数）不是同一个值**。
   暗边窗固定在 r=2 的最差位置供各档 A/B，因此**不是每一档自己的最差处**
   （r=1 的全局最差在别处，0.2571/0.2956 > 窗内 0.2197/0.2527）。引用时必须写明口径。
