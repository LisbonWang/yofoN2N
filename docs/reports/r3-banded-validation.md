# r3 递归输出层分带验证（test 集 10 例）

- 划分：`test`，10 例；产物 JSON：`outputs/eval_1609v2_h2f_128_banded_test.json`
- 推理：`unet3d`，分块 tiled（H/W+ D） patch_hw=256 overlap_d=16 overlap_hw=16，voxel_depth=128
- 分带键：`M2` 输出（去噪后 μ 值，> tissue_floor=0.01），lo=0.2 / hi=0.4（低=水/软组织，中=过渡，高=骨/牙釉质）

## 判据

1. **软组织封顶**（M3/M2 ≤ 1.02）：0.987x → ✅ 成立（软组织未越过 M2，≤2% 视为持平）
2. **骨区超越**（M3/M2 < 1）：0.898x → ✅ 成立（骨/牙釉质在 M2 上再递归一层）
3. **全带低于 full**：✅ 成立（去噪方向正确）

- 过渡带 M3/M2 = 0.967x（smoothstep 混合的中间态）
- 全局：M3 相对 M2 0.979x；相对 full 削减 71.5%
- **门控结论：PASS**
