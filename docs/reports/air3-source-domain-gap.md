# 同一组权重、不同来源体数据：AIR3 r0–r4b 的降噪行为对照

> 2026-09-20。对象：`outputs/air3_ypdl0027_bhc_5models/`。
> 起因：`full.ex.raw` 上 r3b/r4b 的全局 σ 削减只有 −39.0 / −44.7 %，
> 而同一批权重在同目录 `full.bhc.raw` 上是 −75.0 / −79.3 %，一度被读成"分布外输入"。
> 补入同 study 的 plain 域 `full.raw` 后，结论被推翻：**这是输入本身的噪声水平不同，
> 不是泛化失败。**

**不同患者最细频带只有 0.018，external 是 0.838 —— 相差 46 倍，不可能是巧合。**
external 与这个 study 是**同一解剖**，只是重建基线不同（最细频带相差最大，
说明差在纹理/核函数，不在解剖）。

补充：外部卷的最佳配准位移是 (0,0,0)（±2 体素内），线性拟合
`external ≈ 0.9481 × bhc + 0.0240`，做灰度校正后高通相关仍是 0.8327、Dice 0.7002，
**所以既不是平移错位，也不是全局灰度缩放。**

强度分位差（组织区，external − bhc）：p1 −0.0063 / p25 +0.0130 / p50 +0.0048 /
p75 +0.0114 / **p90 +0.0583 / p95 +0.0421** / p99 +0.0019 / p99.9 +0.0075。
在 0.29–0.39 一段被抬高，于是 `>0.4` 的体素数变成 1.45 倍（6,772,598 vs 4,674,231），
其中只有 16.6 % 与原骨掩码相邻 —— **不是骨变多，是阈值附近的人口被整体推上去了。**

> 因此 external 用**它自己的**掩码分带是失真的：high 带 σ 会报 0.03328（输入）和
> 0.01892（r4b），是阈值污染，不是噪声。跨来源比较必须用**共掩码**。

## 4. 结论

1. **`full.raw`（plain）与 `full.bhc.raw` 是同一基线**：全局削减 −75.1/−79.5 % 对
   −75.0/−79.3 %，逐轮误差 <0.2 个百分点，平坦块削减倍数逐轮完全重合。
   模型对"非 BHC 域"没有任何退化，`full.bhc.raw` 不是这份数据里特殊的那一卷。
2. **`full.ex.raw` 与 YPDL-26A-0027 是同一解剖**（最细频带相关 0.838 vs 不同患者 0.018），
   零位移、灰度差 <5 %，但**重建基线不同**：最细频带纹理大幅改变，
   0.29–0.39 一段强度被抬高（>0.4 体素数 1.45×）。
3. **它的输入本身噪声就低 3.2 倍**（平坦块 0.00405 vs 0.01282）。
   模型在纯噪声区对它的削减倍数与在训练域内完全一致，"只削 40 %" 是输入起点决定的。
4. **不要用 external 自己的阈值掩码分带**（high 带会被 0.4 阈值污染，报出 0.03328 这种数）；
   跨来源一律用共掩码。
5. 仍然**不能**由 σ 断言骨小梁有没有被磨平 —— Immerkaer 只量高频能量。
   本报告能证明的是"模型行为未退化、差距来自输入"，结构保留与否要落到 ROI 大图。
